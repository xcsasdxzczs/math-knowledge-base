## 退化与循环

### 退化现象

- **退化**：某基变量取值为 0（基可行解对应的顶点有冗余约束）
- **循环**：退化时可能反复进出同一组变量
- **Bland 规则**：始终选下标最小的 $\sigma_j > 0$ 的变量进基，可防止循环
- **实际中退化常见，循环极罕见**

### 退化示例

考虑约束：

$$
x_1 + x_2 \leq 4, \quad x_1 \leq 2, \quad x_2 \leq 2, \quad x_1, x_2 \geq 0
$$

化标准形后加入松弛变量 $s_1, s_2, s_3$，初始基可行解为 $(0, 0, 4, 2, 2)$。但三条约束直线交于点 $(2, 2)$，该点同时使 $s_1 = 0, s_2 = 0, s_3 = 0$，即三个基变量中有一个取值为 0——这就是退化。

> 退化的本质：可行域的某个顶点对应多于 $m$ 个约束的交点（冗余约束），导致基不唯一。

## 人工变量法概述

### 为什么需要人工变量

单纯形法需要一个**初始基可行解**作为起点。当约束全部是 $\leq$ 型时，松弛变量天然构成初始基。但当约束含 $\geq$ 或 $=$ 型时，没有现成的单位矩阵作初始基。

**解决思路**：人工构造一个"虚拟基"，通过引入人工变量 $a_i$ 把问题变为有初始基的形式，然后通过求解过程把人工变量"赶出"基。

### 两种主流方法

| 方法 | 核心思想 | 优点 | 缺点 |
|------|---------|------|------|
| **大 M 法** | 在目标函数中给人工变量一个巨大惩罚系数 $M$ | 概念简单，一步求解 | $M$ 取值敏感，数值不稳定 |
| **两阶段法** | 分两阶段求解，第一阶段消去人工变量 | 数值稳定，无 $M$ 选择问题 | 需要两次单纯形迭代 |

---

## 大 M 法

### 原理

在目标函数中，给人人工变量 $a_i$ 赋一个极大的惩罚系数 $M$（max 问题中取 $-M$，min 问题中取 $+M$），使得只要人工变量取正值，目标函数就急剧恶化。单纯形法自然会驱使人工变量趋向 0。

### 构造方式

原问题（ max 型）：

$$
\max \ z = c^T x, \quad Ax = b, \quad x \geq 0
$$

引入人工变量 $a \geq 0$ 后：

$$
\max \ z = c^T x - M \sum a_i, \quad Ax + a = b, \quad x, a \geq 0
$$

此时初始基为人工变量 $a_1, \cdots, a_m$ 对应的单位矩阵。

### 大 M 法的缺陷

- $M$ 太小：人工变量可能不被完全赶出基
- $M$ 太大：数值计算中产生舍入误差，导致结果不准
- 实际中推荐使用**两阶段法**替代

## 两阶段法

### 核心思想

把求解过程分为两个阶段：

**第一阶段**：构造辅助问题，目标是**最小化人工变量之和**，找到一个原问题的基可行解。

**第二阶段**：以第一阶段的最优基为初始基，去掉人工变量，求解原问题。

---

### 第一阶段详解

**辅助问题构造**：

对原问题 $Ax = b, x \geq 0$（已化标准形，但无现成初始基），引入人工变量 $a_1, \cdots, a_m$：

$$
\min \ w = a_1 + a_2 + \cdots + a_m
$$

$$
\text{s.t.} \quad Ax + a = b, \quad x \geq 0, \quad a \geq 0
$$

**初始基**：人工变量 $a_1, \cdots, a_m$ 对应 $m \times m$ 单位矩阵，初始基可行解为 $x = 0, a = b$（要求 $b \geq 0$，若有 $b_i < 0$ 则该行乘 $-1$）。

**求解辅助问题**（用单纯形法）：

- 若 $w^{\ast} = 0$ → 所有人工变量为 0，找到了原问题的一个基可行解，进入第二阶段
- 若 $w^{\ast} > 0$ → 至少有一个人工变量仍为正，说明原问题**无可行解**，停止

---

### 第一阶段结束时的人工变量处理

当 $w^{\ast} = 0$ 时，人工变量虽然取值为 0，但可能仍在基中。需分情况处理：

**情况 1：人工变量全部退出基** → 直接进入第二阶段

**情况 2：某人工变量仍在基中（取值为 0）** → 需要将其替换出基：

- 在该人工变量所在行中，找原问题变量列的非零元素（ $\bar{a}_{rj} \neq 0$）
- 以该元素为主元做旋转运算，将人工变量替换为原变量
- 若该行所有原变量系数均为 0 → 该约束是冗余约束，直接删去该行

---

### 第二阶段详解

1. **删除人工变量列**：从单纯形表中删去所有人工变量对应的列
2. **替换目标函数**：将目标函数换回原问题的 $z = c^T x$
3. **重新计算检验数**：用第一阶段最终基的 $B^{-1}$ 计算 $\sigma_j = c_j - c_B^T B^{-1} a_j$
4. **继续单纯形迭代**：从当前基可行解出发，求原问题最优解

---

### 两阶段法流程图

```
原问题 Ax = b, x >= 0（无初始基）
    │
    ▼
引入人工变量 a >= 0
    │
    ▼
第一阶段：min w = Σa_i, s.t. Ax + a = b
    │
    ├── w* > 0 → 原问题无可行解，结束
    │
    └── w* = 0 → 找到基可行解
                    │
                    ▼
              人工变量还在基中？
                    │
              ├── 是 → 旋转替换出基（或删冗余行）
              │
              └── 否 → 直接进入第二阶段
                    │
                    ▼
第二阶段：删去人工变量列
    │                         换回原目标函数 z = c^T x
    │                         重新计算检验数
    │                         继续单纯形迭代
    ▼
  求得最优解
```

## 两阶段法手算示例

**原问题**：

$$
\max \ z = 3x_1 - x_2 - x_3
$$

$$
\text{s.t.} \quad x_1 - 2x_2 + x_3 \leq 11
$$

$$
-4x_1 + x_2 + 2x_3 \geq 3
$$

$$
2x_1 - x_3 = -1
$$

$$
x_1, x_2, x_3 \geq 0
$$

### 化标准形

- 约束 1（ $\leq$）：加松弛变量 $s_1$
- 约束 2（ $\geq$）：减剩余变量 $s_2$
- 约束 3（ $=，b_3 < 0$）：两边乘 $-1$ → $-2x_1 + x_3 = 1$

$$
x_1 - 2x_2 + x_3 + s_1 = 11
$$

$$
-4x_1 + x_2 + 2x_3 - s_2 = 3
$$

$$
-2x_1 + x_3 = 1
$$

此时 $s_1$ 可作为第一个基变量，但第 2、3 行没有现成基变量。

### 第一阶段

引入人工变量 $a_1, a_2$（第 2、3 行）：

$$
\min \ w = a_1 + a_2
$$

$$
x_1 - 2x_2 + x_3 + s_1 = 11
$$

$$
-4x_1 + x_2 + 2x_3 - s_2 + a_1 = 3
$$

$$
-2x_1 + x_3 + a_2 = 1
$$

初始基： $s_1, a_1, a_2$，初始基可行解： $(0, 0, 0, 11, 0, 0, 3, 1)$

**第一阶段初始单纯形表**：

| 基 | $x_1$ | $x_2$ | $x_3$ | $s_1$ | $s_2$ | $a_1$ | $a_2$ | $b$ |
|-----|-------|-------|-------|-------|-------|-------|-------|-----|
| $s_1$ | 1 | -2 | 1 | 1 | 0 | 0 | 0 | 11 |
| $a_1$ | -4 | 1 | 2 | 0 | -1 | 1 | 0 | 3 |
| $a_2$ | -2 | 0 | 1 | 0 | 0 | 0 | 1 | 1 |

检验数（min 问题， $\sigma_j = c_j - z_j$，人工变量价值系数为 1，其余为 0）：

$z_j = \sum c_B \cdot a_{ij}$，其中 $c_{s_1} = 0, c_{a_1} = 1, c_{a_2} = 1$

- $\sigma_{x_1} = 0 - (0 \times 1 + 1 \times (-4) + 1 \times (-2)) = 0 - (-6) = 6 > 0$

> min 问题中 $\sigma_j > 0$ 表示该变量可使 $w$ 减小，应进基。进基变量选 $\sigma_j$ 最大的。

经过两轮迭代后（过程略），第一阶段最优值为 $w^{\ast} = 0$，人工变量全部退出基。得到原问题的初始基可行解，进入第二阶段。

### 第二阶段

删除人工变量列 $a_1, a_2$，目标函数换回 $z = 3x_1 - x_2 - x_3$，以第一阶段的最优基继续迭代，最终求得原问题最优解。

**最终结果**： $x_1 = 4, x_2 = 0, x_3 = 9, z^{\ast} = 3$

## Python 实现

### 两阶段法完整实现

```python
import numpy as np


TOL = 1e-10


def _pivot(table, row, col):
    """对单纯形表进行一次主元变换。"""
    pivot = table[row, col]

    if abs(pivot) <= TOL:
        raise ValueError("主元过小，不能进行旋转运算。")

    table[row, :] /= pivot

    for i in range(table.shape[0]):
        if i != row:
            factor = table[i, col]
            if abs(factor) > TOL:
                table[i, :] -= factor * table[row, :]

    # 清除浮点误差
    table[np.abs(table) < TOL] = 0.0


def _simplex_tableau(c, table, basis, phase_name="单纯形法",
                     max_iter=1000):
    """
    使用已有的规范单纯形表进行最大化单纯形迭代。

    参数:
        c:
            最大化问题的目标函数系数。
        table:
            单纯形表 [A_bar | b_bar]，当前基列应为单位阵。
        basis:
            当前基变量下标。
        phase_name:
            输出时显示的阶段名称。

    返回:
        status:
            "optimal" 或 "unbounded"
        x:
            当前解。
        z:
            当前目标函数值。
        table:
            最终单纯形表。
        basis:
            最终基。
    """
    c = np.asarray(c, dtype=float)
    table = np.asarray(table, dtype=float)
    basis = list(basis)

    m = table.shape[0]
    n = len(c)

    if table.shape[1] != n + 1:
        raise ValueError("单纯形表列数必须等于变量数加 1。")

    for iteration in range(1, max_iter + 1):

        if m == 0:
            zj = np.zeros(n)
        else:
            cb = c[np.asarray(basis, dtype=int)]
            zj = cb @ table[:, :n]

        # 对最大化问题：
        # sigma_j = c_j - z_j
        sigma = c - zj
        sigma[np.abs(sigma) < TOL] = 0.0

        # 所有检验数 <= 0，达到最优
        if np.all(sigma <= TOL):
            x = np.zeros(n)

            for i, bi in enumerate(basis):
                value = table[i, -1]
                if abs(value) < TOL:
                    value = 0.0
                x[bi] = value

            z = float(c @ x)

            print(f"  {phase_name}达到最优")
            print(f"  当前解: {np.round(x, 6)}")
            print(f"  当前目标值: {z:.6f}")

            return "optimal", x, z, table, basis

        # 选择检验数最大的变量进基
        j_enter = int(np.argmax(sigma))

        col = table[:, j_enter]
        rhs = table[:, -1]

        valid_rows = np.where(col > TOL)[0]

        if len(valid_rows) == 0:
            print(f"  {phase_name}无界")
            return "unbounded", None, np.inf, table, basis

        ratios = rhs[valid_rows] / col[valid_rows]

        # 处理极小的负数误差
        ratios[np.abs(ratios) < TOL] = 0.0

        min_ratio = np.min(ratios)

        # 如果存在并列，取下标最小的行
        candidate_rows = valid_rows[
            np.where(np.abs(ratios - min_ratio) <= TOL)[0]
        ]
        i_leave = int(candidate_rows[0])

        leaving_var = basis[i_leave]
        pivot_value = table[i_leave, j_enter]

        print(
            f"  迭代 {iteration}: "
            f"x{j_enter + 1} 进基，"
            f"x{leaving_var + 1} 出基，"
            f"theta={min_ratio:.6f}，"
            f"主元={pivot_value:.6f}"
        )

        _pivot(table, i_leave, j_enter)
        basis[i_leave] = j_enter

    raise RuntimeError(f"超过最大迭代次数 {max_iter}，算法可能发生循环。")


def _remove_artificial_variables(table, basis, n_original):
    """
    将仍在基中的零值人工变量换出，并删除冗余约束。

    参数:
        table:
            第一阶段最终单纯形表，包含人工变量列。
        basis:
            第一阶段最终基。
        n_original:
            原变量总数，包括松弛变量和剩余变量，但不包括人工变量。

    返回:
        删除人工变量列后的 table 和 basis。
    """
    basis = list(basis)

    while True:
        artificial_row = None

        for i, bi in enumerate(basis):
            if bi >= n_original:
                artificial_row = i
                break

        # 基中已经没有人工变量
        if artificial_row is None:
            break

        i = artificial_row

        # 寻找一个非基原变量，把人工变量换出
        candidates = []

        for j in range(n_original):
            if j not in basis and abs(table[i, j]) > TOL:
                candidates.append(j)

        if candidates:
            j_enter = candidates[0]

            print(
                f"  将人工变量 x{basis[i] + 1} 换出，"
                f"原变量 x{j_enter + 1} 进基"
            )

            _pivot(table, i, j_enter)
            basis[i] = j_enter
        else:
            # 没有原变量可以进入该行
            if abs(table[i, -1]) > 1e-7:
                raise ValueError(
                    "人工变量无法换出且值非零，原问题不可行。"
                )

            # RHS=0 且没有原变量可换入，说明这是冗余约束
            print(
                f"  删除冗余约束行 {i + 1}，"
                f"对应人工变量 x{basis[i] + 1}"
            )

            table = np.delete(table, i, axis=0)
            basis.pop(i)

    # 删除所有人工变量列，只保留原变量列和 RHS
    table = np.hstack([
        table[:, :n_original],
        table[:, -1].reshape(-1, 1)
    ])

    table[np.abs(table) < TOL] = 0.0

    return table, basis


def two_phase_simplex(c, A, b):
    """
    两阶段法求解线性规划：

        max z = c^T x
        s.t. A x = b
             x >= 0

    参数:
        c: 目标函数系数，长度为 n
        A: 约束系数矩阵，形状为 m × n
        b: 右端项，长度为 m

    返回:
        x_opt: 最优解；不可行或无界时为 None
        z_opt: 最优值；不可行时为 None，无界时为 np.inf
    """
    c = np.asarray(c, dtype=float).copy()
    A = np.asarray(A, dtype=float).copy()
    b = np.asarray(b, dtype=float).copy()

    if A.ndim != 2:
        raise ValueError("A 必须是二维矩阵。")

    m, n = A.shape

    if c.shape != (n,):
        raise ValueError("c 的长度必须等于 A 的列数。")

    if b.shape != (m,):
        raise ValueError("b 的长度必须等于 A 的行数。")

    # 确保 b >= 0
    for i in range(m):
        if b[i] < 0:
            A[i, :] *= -1
            b[i] *= -1

    # ==================================================
    # 第一阶段
    # ==================================================
    print("=" * 60)
    print("第一阶段：min w = Σa_i，等价于 max (-Σa_i)")
    print("=" * 60)

    # 添加 m 个人工变量
    A_aux = np.hstack([A, np.eye(m)])

    # 最大化 -sum(a_i)
    c_phase1 = np.concatenate([
        np.zeros(n),
        -np.ones(m)
    ])

    # 初始基全部为人工变量
    basis = list(range(n, n + m))

    # 初始单纯形表
    table = np.hstack([
        A_aux,
        b.reshape(-1, 1)
    ])

    status1, x_phase1, z_phase1, table, basis = _simplex_tableau(
        c_phase1,
        table,
        basis,
        phase_name="第一阶段"
    )

    if status1 == "unbounded":
        # 理论上第一阶段 max(-sum a) 不应该无界
        print("第一阶段辅助问题异常无界，请检查输入或数值稳定性。")
        return None, None

    # z_phase1 = -w
    w_opt = float(np.sum(x_phase1[n:]))

    if abs(w_opt) < 1e-8:
        w_opt = 0.0

    print(f"\n第一阶段结果：w* = {w_opt:.10f}")

    if w_opt > 1e-7:
        print("w* > 0，原问题无可行解。")
        return None, None

    print("w* = 0，原问题存在基可行解。")

    # 将基中的零值人工变量换出，并删除人工变量列
    table, basis = _remove_artificial_variables(
        table,
        basis,
        n_original=n
    )

    # ==================================================
    # 第二阶段
    # ==================================================
    print()
    print("=" * 60)
    print("第二阶段：max z = c^T x")
    print("=" * 60)

    status2, x_opt, z_opt, table, basis = _simplex_tableau(
        c,
        table,
        basis,
        phase_name="第二阶段"
    )

    if status2 == "unbounded":
        print("原问题存在无界解。")
        return None, np.inf

    return x_opt, z_opt

], dtype=float)

    [1, -2, 1, 1, 0],
    [-4, 1, 2, 0, -1],
    [-2, 0, 1, 0, 0]
], dtype=float)

print("=" * 60)

    else:

    print(f"x1 = {x_opt[0]:.6f}")
```

> 与手算结果 $x_1 = 4, x_2 = 1, x_3 = 9, z = 2$ 完全一致。

### 两阶段法手写实现

```matlab
function [x_opt, z_opt] = TwoPhaseSimplex(c, A, b)
% TWOPHASESIMPLEX 两阶段法求解线性规划
%   max z = c*x, s.t. A*x = b, x >= 0
%   自动引入人工变量

    [m, n] = size(A);
    A = double(A);  b = double(b);  c = double(c);
    
    % 确保 b >= 0
    for i = 1:m
        if b(i) < 0
            b(i) = -b(i);
            A(i, :) = -A(i, :);
        end
    end
    
    %% ========== 第一阶段 ==========
    fprintf('==========\n');
    fprintf('第一阶段: min w = sum(a_i)\n');
    fprintf('==========\n');
    
    % 构造辅助问题
    A_aux = [A, eye(m)];           % 添加人工变量列
    c_aux = [zeros(1, n), ones(1, m)];  % min w = sum(a_i)
    basis = (n+1):(n+m);           % 初始基 = 人工变量
    
    [x_aux, w_opt] = SimplexSolve(c_aux, A_aux, b, basis, false);
    fprintf('第一阶段结果: w* = %.6f\n', w_opt);
    
    if w_opt > 1e-6
        fprintf('w* > 0，原问题无可行解！\n');
        x_opt = []; z_opt = NaN;
        return;
    end
    
    fprintf('w* = 0，找到基可行解，进入第二阶段\n\n');
    
    %% ========== 第二阶段 ==========
    fprintf('==========\n');
    fprintf('第二阶段: max z = c^T x\n');
    fprintf('==========\n');
    
    x_opt = SimplexSolve(c, A, b, basis, true);
    z_opt = c * x_opt';
    
    fprintf('\n最终结果: z = %.4f\n', z_opt);
end

function [x, obj_val] = SimplexSolve(c, A, b, basis, is_max)
% 单纯形法核心迭代
    [m, n] = size(A);
    Table = [A, b(:)];
    cb = c(basis);
    
    iter = 0;
    while true
        iter = iter + 1;
        zj = cb * Table(:, 1:n);
        sigma = c - zj;
        
        if is_max
            if all(sigma <= 1e-10), break; end
            [~, j_enter] = max(sigma);
        else
            if all(sigma >= -1e-10), break; end
            [~, j_enter] = min(sigma);
        end
        
        col = Table(:, j_enter);
        theta = inf(m, 1);
        for i = 1:m
            if col(i) > 1e-10
                theta(i) = Table(i, end) / col(i);
            end
        end
        
        if all(isinf(theta))
            fprintf('无界解！\n');
            x = []; obj_val = inf; return;
        end
        
        [~, i_leave] = min(theta);
        fprintf('  迭代 %d: 进基 x%d, theta=%.4f\n', iter, j_enter, theta(i_leave));
        
        pivot = Table(i_leave, j_enter);
        Table(i_leave, :) = Table(i_leave, :) / pivot;
        for i = 1:m
            if i ~= i_leave
                Table(i, :) = Table(i, :) - Table(i, j_enter) * Table(i_leave, :);
            end
        end
        
        basis(i_leave) = j_enter;
        cb(i_leave) = c(j_enter);
    end
    
    x = zeros(1, n);
    for i = 1:m
        x(basis(i)) = Table(i, end);
    end
    obj_val = c * x';
    fprintf('  最优解: '); fprintf('%.4f ', x); fprintf('\n');
    fprintf('  最优值: %.4f\n', obj_val);
end
```

## 方法对比总结

| 维度 | 大 M 法 | 两阶段法 |
|------|---------|---------|
| 原理 | 目标函数加重惩罚 | 分两阶段消去人工变量 |
| 求解次数 | 一次单纯形 | 两次单纯形 |
| 数值稳定性 | 差（ $M$ 过大导致误差） | 好 |
| 人工干预 | 需选择 $M$ 值 | 无需选参数 |
| 实际推荐 | 教学演示 | 工程首选 |

> **工程实践建议**：优先使用两阶段法。当用 Python(PuLP) 或 MATLAB(linprog) 时，底层求解器会自动处理初始基问题，无需手动实现两阶段法。
